# 视觉验收标准

当前没有 UI 参考图时，按本文件做人工验收。未来加入参考图后，本文件仍作为最低标准。

## 全局

- 一眼能区分 Maker 与 Runner 模式。
- 左侧工具栏、中央地图、右侧 Inspector 的层级清晰。
- 当前选中工具、选中实体和 hover 状态都明确可见。
- 错误反馈出现在操作附近或状态栏，不只写入控制台。

## 大地图

- Zone 节点之间的 edge 关系清楚。
- Zone 标签可读，缩放后不造成严重重叠。
- 可达、锁定、隐藏、已发现状态有不同视觉表达。
- 当前所在 zone 在 Runner 模式下醒目。

## 小地图

- 方形格子边界可读。
- Tile、building、NPC、player 不会视觉混淆。
- 不可行走格和可行走格有明确差异。
- 放置或移动预览能看出合法/非法状态。

## 工具栏与 Inspector

- 工具按钮不依赖文字也能大致理解，文字 tooltip 可补充。
- Inspector 字段按基础信息、行为规则、引用关系、危险操作分组。
- 删除操作必须使用危险色或确认状态。

## 对话与雷达

- 对话框适合玩家观看，文字足够大。
- 对话选项和继续按钮明确。
- 雷达扫描中的状态、结果数量和目标提示清晰。
- 雷达标记不会永久污染地图视图。
