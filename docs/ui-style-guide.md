# UI 样式指南

当前没有 UI 参考图时，以下规则作为默认视觉方向。

## 视觉关键词

- GM 工具台
- 暗色界面
- 地图纸张与战术网格
- 清晰的信息层级
- 低干扰的游戏氛围

## 颜色

- 背景：深灰或近黑，避免纯黑。
- 面板：深蓝灰或炭灰，边框低对比。
- 主强调色：琥珀色或青蓝色，用于选中工具、当前节点和主要按钮。
- 危险色：柔和红色，用于删除、无效放置、锁定路径。
- 可交互高亮：高亮边框或外发光，不依赖单一颜色表达状态。

## 字体与密度

- UI 字体优先使用系统 sans-serif。
- 地图标签应短、清晰、可缩放。
- Inspector 表单密度中等，不做极简留白，也不堆满控制项。
- 对话框文字应比 Inspector 更大，适合桌面展示给玩家观看。

## 面板风格

- 面板使用轻微圆角和边框。
- 常驻面板背景不透明或半透明度极低，保证可读性。
- 弹出层可以使用轻微阴影，但不使用强烈玻璃拟态。

## 地图元素风格

- 大地图 zone 使用明确节点形状，选中状态必须可见。
- 大地图 edge 使用线条连接，并支持 hover/selected 状态。
- 小地图格线要可读但不能压过 tile 内容。
- NPC、building、事件点必须能一眼区分。

## 禁止事项

- 不做通用后台管理系统风格。
- 不把编辑器做成移动端优先。
- 不用大量渐变和装饰影响地图可读性。
- 不依赖图片素材才能表达基本交互状态。
