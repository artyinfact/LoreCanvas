# UI 布局规范

本文件是不依赖参考图的布局约束。后续图片参考只能补充，不应推翻这里的核心信息架构。

## 全局布局

- 应用采用三栏编辑器布局：左侧工具栏、中央 PixiJS 画布、右侧 Inspector。
- 顶部保留模式栏，显示 Maker/Runner、当前地图层、项目名、Save/Load。
- 底部区域默认收起，只在对话、事件日志或雷达结果需要时展开。
- PixiJS 画布始终是视觉中心，不允许被常驻面板大面积遮挡。

## 推荐尺寸

- 左侧工具栏宽度：72px 到 96px。
- 右侧 Inspector 宽度：280px 到 360px。
- 顶部模式栏高度：48px 到 64px。
- 底部对话框高度：160px 到 240px。
- 雷达面板宽度：280px 到 360px，可停靠右下角或 Inspector 下方。

## Maker 模式

- 左侧工具栏常驻。
- 右侧 Inspector 常驻；未选中实体时显示当前地图说明和快捷操作。
- 中央画布支持缩放和平移。
- 当前地图层必须醒目显示：`World Map` 或 `Local Map: <name>`。

## Runner 模式

- 隐藏编辑工具，仅保留必要的导航、时间、雷达和日志控件。
- Inspector 改为只读信息面板或上下文提示。
- 对话框出现时可遮挡底部，但不能遮挡玩家当前位置或当前交互目标。

## 响应式边界

第一版优先支持桌面宽屏。小于 1024px 宽度时可以显示“不支持窄屏编辑”的提示，不必实现移动端编辑器。
